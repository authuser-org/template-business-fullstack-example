## Convención de entornos

- Entorno de negocio: `APP_ENV=dev|pre|pro`
- Entorno técnico runtime: `NODE_ENV=development|test|production`

Estas convenciones deben mantenerse en todos los stacks para asegurar trazabilidad y despliegues homogéneos.
